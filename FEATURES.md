# Features

 - Flashtool für Geräte von FRITZ! aka AVM.
 - DieFlashe ist unabhängig von FRITZ! aka AVM.
 - Über eine Suche das Gerät beim Bootvorgang finden
 - Das Gerät beim Bootvorgang im Bootloader anhalten
 - Den Environment- und Counter-Inhalt wird angezeigt
 - Die Environment-Variablen können bearbeitet werden
 - Informationen über die MTDs können angezeigt werden 
 - Beliebige benutzerdefinierte FTP-Befehle ausführen
 - Das Gerät kann rebooten werden
 - Details des Bootloaders wie ADAM2 und EVA werden angezeigt
 - Details des Gerätes wie Name und Firmwareversion werden angezeigt
 - Details einer Firmware wie Gerät und Version werden angezeigt
 - Der Status von Pinganfragen werden angezeigt
 - Die zu verwendende Netzwerkkarte kann ausgewählt werden
 - Die zu nutzende freie IP kann festgelegt werden
 - Die Signatur einer Firmware kann validiert werden
 - Für die Signaturprüfung können [eigene Keys](SIGNATUR.md) verwendet werden
 - Fehler in der Struktur der Firmware werden angezeigt
 - Die Modifikationen Freetz und Freetz-NG werden erkannt
 - Der verfügbare Arbeitsspeicher (memsize) ist begrenzbar
 - Die Zielpartition (linux_fs_start) des Flashens ist auswählbar
 - Die Unterstürzung von Coldflash (avm_fwupdate) ist aktivierbar
 - Die Übertragungsrate des Flashvorganges wird angezeigt
 - Die Logausgabe ist bei vergrößertem Programmfenster sichtbar
 - Im Datenverzeichnis werden alle Logdateien gespeichert
 - Es werden auch alle ausgelesenen Environments gespeichert
 - Außerdem werden alle anonymisierten Environments gespeichert
 - Das Programm ist lokalisiert in deutsch und in englisch

### Was DieFlashe nicht macht
 - Flashen von Geräten mit Docsis 3.1 (6591, 6660, 6670, 6690 und 6690 Pro)
 - Flashen von Geräten mit Kernel 2.4, ein AVM-Update aktualisiert das Flash-Layout
 - Ein Update des Bootloaders
 - Einen Werksreset durchführen
